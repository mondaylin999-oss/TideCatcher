# Name-free voice lines

When the player picks their own names, the game cannot say those names out loud. For the lines below it plays a second recording that says "she" or "her cat" instead of "Thiri" or "Shwe". The subtitles still show the player's names.

Record each line in the **same voice** as the original clip (Kokoro-82M, the same voice blend), save it as MP3 next to the original, and use the file name shown. Until a file exists, that line shows as text only.
