# Park map: process

Map for **Night 3 · The Park** (Lonely and Shy). In the game: [`game/assets/park/park-night.webp`](../../../game/assets/park/park-night.webp), drawn by `drawParkWorld()` in `game/js/game.js`.

| File | Step |
|---|---|
| `1-original-chatgpt.webp` | Night park generated with **ChatGPT** by _TEAM TO FILL (name)_ on 17 Oct 2026 (1280 × 426) |
| `2-platforms-removed.webp` | The four painted-in floating grass platforms removed |
| `3-regraded.webp` | Upscaled 4× with the Real-ESRGAN anime model (open-source AI upscaler) and scaled to 2×; blues moved toward indigo so the blue Lonely Moodling stands out; darks lifted; warm glow and light pools added under the street lamps; soft moon glow |
| `4-in-game.png` | Screenshot in the game |

Steps 2–3 and the in-game parts were done on 17 Oct 2026 with Claude (Anthropic).

## In the game
- The picture repeats along the level, mirrored every other time, moving at 0.85× camera speed.
- Drawn in code so they match the collisions: grass edge with small coloured flowers, stone path, bushes (hiding places for Lonely and Shy), playground decks on poles (the platforms).
