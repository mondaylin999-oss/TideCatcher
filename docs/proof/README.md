# Proof of work

Evidence of how TideCatcher's art was made, for Digit7 Jam 2026 judging.

Each folder follows the same order:

| Folder | What goes in it |
|---|---|
| `01-*` | Where it started: sketches, photos of paper drawings, source images |
| `02-*` | Work in progress: screenshots, comparisons, layered files |
| `03-*` | The final result, as used in the game |
| `PROCESS.md` | Who made it, when, with which tools, and what was changed |

- `cats/` — the 8 cat breeds the player can choose
- `moodlings/` — the 8 feelings the cat catches
- `intro-scenes/` — the 8 opening story pictures

**Rules**
- Keep files under ~5 MB. Put videos, timelapses and large .psd / .procreate / .kra files on Google Drive and link them in `PROCESS.md`.
- Name files with a number first so they sort in order (`1-sketch.png`, `2-colour.png`).
- Anything made or changed with AI must also be listed in [`/AI-DECLARATION.md`](../../AI-DECLARATION.md).
